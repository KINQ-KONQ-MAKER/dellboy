Étape 4

🧹 Nettoyage

Supprime les langues Office en trop et remet à plat les redistribuables Visual C++ (MSVCP140.dll).

Sécurité : une langue n'est retirée que si la même appli existe dans la langue conservée.
Désinstalle toutes les versions v14, réinstalle la dernière x64 + x86, puis vérifie MSVCP140.dll. Les redistribuables 2005–2013 sont conservés.

Comment lancer un script (.cmd)

  1. Télécharge le script. Si le navigateur l'avertit, choisis Conserver.
  2. Double-clique sur le fichier dans Téléchargements, puis accepte la demande d'élévation (UAC).
  3. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires → Exécuter quand même.
  4. La fenêtre reste ouverte à la fin avec le résumé. Redémarre si demandé, puis passe au script suivant (Windows → Dell → Applications → Nettoyage).

Le .cmd contient le script PowerShell : il se relance lui-même en administrateur et contourne la stratégie d'exécution pour ce lancement uniquement. Rien n'est modifié durablement sur le poste.
